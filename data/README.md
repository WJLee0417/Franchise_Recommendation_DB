# 입력 데이터 안내

이 저장소에는 원천 데이터와 가공 데이터 파일을 포함하지 않습니다.

## 필요한 데이터

- 서울시 상권분석서비스 기반 상권·인구·소득·매출·점포·집객시설 데이터
- 공정거래위원회 가맹사업정보제공시스템 기반 프랜차이즈 정보
- 입력 지역 사례 데이터: `원천동.xlsx`

기본 노트북은 다음 경로를 사용합니다.

```text
data/원천동.xlsx
```

다른 디렉터리를 사용하려면 `FRANCHISE_INPUT_DATA_DIR` 환경변수를 설정합니다.

## 공개 저장소에 데이터를 넣지 않은 이유

프로젝트 당시 수집·가공한 파일에는 재배포 허용 범위를 별도로 확인해야 하는 데이터가 포함되어 있습니다. 따라서 저장소에는 코드, 스키마, 설계 문서만 공개하고 원천 데이터는 사용자가 각 제공처의 이용 조건에 따라 직접 확보하는 방식을 사용합니다.
