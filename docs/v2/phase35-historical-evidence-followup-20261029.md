# Phase 3-5 — 2026-10-29 공식 자료 추가 검증 (역사적 증빙 트랙)

## 실질적으로 추가 확인된 사실

### G02 상권 경계 공간 버전: **BLOCKED 유지**

서울 공식 데이터 허브의 영역 상권 명세는 '시계열: -'로 표시한다(https://data.seoul.go.kr/bsp/wgs/dataView/data300View/10056.do). 영역 데이터에는 상권 코드/명칭·좌표·면적이 있지만 개별 상권의 유효 시작일/종료일 필드가 없다. 원본 2022Q1–2023Q2에 적용되는 **폴리곤 버전 이력**을 이 명세만으로 복원할 수 없다.

서울 공식 OA-15560 파일 목록의 2023-10-23 수정일이나 상권분석서비스의 2022년 공간 구성 설명을 효력시작일로 소급해서는 안 된다. 공식 파일 목록과 실제 파일의 다운로드/원본 SHP 해시/경계 분기별 유효기간 입증은 다른 작업이다. **이번 조사에서 과거 ZIP/SHP 파일 자체는 확보하지 못했다.**

### G03 서울 100업종 분류 적용일: **BLOCKED 유지**

서울 상권분석서비스의 100대 생활밀접업종 공식 PDF(https://golmok.seoul.go.kr/images/100_v3.pdf)에서 서울 CS 업종코드와 한국표준산업분류 제10차 기반 업종 세세분류 대응을 확인했다. 서울시·서울신용보증재단의 2023년 발행 소상공인 생활백서에도 2022년 자료를 대상으로 이 체계가 사용된 사례가 존재한다(https://ms.smc.seoul.kr/attach/record/SEOUL/appendix/a11/A0061039.pdf?time=20260525185632).

다만 **2022년 실제 적용된 분류 릴리스 ID 및 법적·통계적 유효시작/종료일**은 PDF 내용이나 2023년 발행일로부터 알 수 없다. `100_v3.pdf` 파일명 'v3'를 2022년 효력 코드로 사용하지 않는다. 원본 CSV 100개 업종 코드/명칭의 일관성은 확정된 별도의 내부 증거다.

### G06 점포 관측기간: 공식 산식 일부 확인, **BLOCKED 유지**

서울시 공식 데이터 안내 PDF(https://golmok.seoul.go.kr/images/seoul_info.pdf) 2페이지에서 분기는 1~3월, 4~6월, 7~9월, 10~12월로 구분하고 통계 발표에 약 2개월 시차가 있다고 설명한다. 3페이지에서는 점포수의 통계적 범위와 개·폐업률을 '당기 개·폐업 신고 점포수/전체 점포수×100'으로 설명하고, 점포의 영업·폐업 여부를 당기 조건과 연결한다.

이로써 **공식 보고 통계의 단위는 분기이고, 개·폐업률의 공표 산식에는 전체 점포수가 분모로 표기**된다는 근거를 확보했다. 그러나 원본 CSV의 `개업_율`, `폐업_률`은 단순히 동일 분기 `유사_업종_점포_수`로 나눠 재계산했을 때 일부 불일치가 있다. 따라서 특정 2022/2023 배포본의 개업률·폐업률 분모 정의, 자료 수집 기준일, 수정·반올림 이력, FACT의 `observation_period_key`가 기준분기와 동일하다는 근거는 **아직 미확정**이다.

## 현재 엄격한 판정

이 조사로 ① 공식 자료에서 시간차원 부재, ② 업종 체계의 과거 사용 사실, ③ 분기·점포·율의 공개 설명은 확인됐다. 다만 사용자가 목표로 하는 *해당 원본에 적용된 정확한 역사적 폴리곤·분류 릴리스·관측일*은 아직 확보되지 않았다. **G02 / G03 / G06는 전부 BLOCKED를 유지**하고, FACT·DIM을 적재하거나 유효일을 임의 생성하지 않는다.
